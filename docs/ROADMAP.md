# Race Star — порядок этапов

Порядок зафиксирован, чтобы не переспрашивать на каждом шаге. Правило сортировки:
**сначала то, что чинит уже написанное, потом то, что кладётся поверх.**
Каждая новая ось силы роняет все вехи баланса, поэтому оси идут как можно позже
и по одной.

Разбор оригинала — `teardown/FINDINGS.md`. Правила кода — `AGENTS.md`.

---

## Ритуал каждого этапа (без исключений)

1. Механика — из `FINDINGS.md`, а не из головы. Нет данных → помечаем `[X]`.
2. Числа — только в `src/config/*`, каждое с меткой `[F]` / `[~]` / `[X]`.
3. `npx vite build` → `npm run smoke` → `npm run shot <экран>` → `npm run sim`.
4. Новая ось силы → полная переподгонка `npm run sim:tune` + отчёт по трём политикам.
5. **Визуальная сверка** с референсом (шаг 0) — для экранов, где кадр есть.
6. Итог этапа: что сделано, что осталось кривым, что помечено `[X]`.

---

## Шаг 0 — референс-стенд визуальной сверки

**Зачем здесь:** требование «1 в 1 по визуалу» сейчас непроверяемо — кадров
оригинала в репозитории нет. В `FINDINGS.md` они упомянуты как источник, но сами
файлы не сохранены, а `raw/` из git исключён. Без этого шага любая сверка — «на
память», а память врёт.

- скачать 6 скриншотов стора + кадры официальных видео → `teardown/ref/<экран>/`
- `tools/refdiff.mjs` — наш скрин 390×844 и кадр, приведённый к той же ширине, бок о бок
- `npm run shot` расширить на все экраны, добавить `npm run diff <экран>`
- разметить, **у каких экранов кадра нет вообще** — там 1в1 недостижимо в принципе

## Шаг 1 — визуальный проход по готовым экранам

**Зачем здесь:** визуальный язык, заданный сейчас, унаследуют все новые вкладки.
Менять его после шага 5 — переделывать шесть экранов вместо четырёх.

Главный, `Classes`, драйверы, карьера → к кадрам. Список известных расхождений —
в конце файла.

## Шаг 2 — долги баланса (фанаты и гемы)

**Зачем здесь:** до магазина. Гемы — валюта вкладки 6; пока их капает 20% побед
вместо 15%, дневной кап `150` `[F]` выбивается за четверть суток, и цены магазина
не на чем ставить.

- множитель фанатов ×14.8 при цели ×20 — третий этап подряд; границу `fansK` уже
  проверяли, дело в форме экономики
- доля побед 20% при цели 15% — либо цель, либо кап не на месте

## Шаг 3 — вкладка 4: лиги, сезоны, таблица

**Зачем здесь:** лестница лиг — главный множитель дохода (×1.585 за ступень),
14 ступеней, и игрок её **не видит**. Дешёвый этап без переподгонки: модель уже есть.

Standings W/L, `Season History`, `Advance`, прогресс до повышения, награды за лигу.

## Шаг 4 — вкладка 5: награды

**Зачем здесь:** даёт источник гемов помимо побед — то, на чём стоит следующий шаг.

Daily/Weekly задачи со счётчиками `[F]`, Season Pass 10 дней `[F]`, майлстоуны,
Daily Rewards с ротацией, почта.

## Шаг 5 — вкладка 6: магазин

**Зачем здесь:** замыкает экономику — после шага 4 есть приток гемов, теперь есть
куда их деть. Каталог IAP снят с App Store `[F]`.

Гемы за деньги, паки, офферы, `No Ads`, `x2 Resources`, `Sprint Pass`.

## Шаг 6 — вкладка 2: гир драйверов

**Зачем здесь:** первая новая ось силы. Всё, что дешевле и не трогает баланс, уже
сделано. Полная переподгонка обязательна.

Слоты, редкости, уровни, паки с шансами, купоны, merge (`SportTeamGear`).

## Шаг 7 — гараж и машины

**Зачем здесь:** вторая новая ось. В оригинале гаража нет ни на одном публичном
кадре (билд видео 1.2–1.3) → это **целиком наше проектирование**, поэтому кладётся
на уже устоявшийся баланс, а не в середину.

Машины, звёзды, апгрейд, гир машины, цвета/декали, группы по классам.

## Шаг 8 — соревнования

**Зачем здесь:** требует ботов вместо сети, но не трогает кривую дохода —
отдельный контур наград.

Champions Arena (3 тикета/день, медали, ранги), Weekly Tournament (best-of-3,
ротация класса), Cup, клубы и Club Clash.

## Шаг 9 — доборы

Уникальные драйверы (`Unique Cores`), коллекции, аутфиты, Lucky Draw, gift-коды,
аватары и рамки.

## Шаг 10 — финальная сверка и сборка

Полный проход `npm run diff` по всем экранам, прогон 700 ч, APK через build API.
